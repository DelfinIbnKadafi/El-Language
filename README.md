# El Language

El Language is a high-level programming language designed with a custom Virtual Machine (VM) architecture.

The language focuses on simplicity, productivity, and portability while providing an independent execution environment through its Virtual Machine.

![Logo](logo.png)

## Architecture

El Language programs are compiled and executed through the El Virtual Machine.

The Virtual Machine handles program execution, memory management, and runtime operations, allowing El Language applications to run consistently across different systems.

## Features

- High-level programming language
- Custom Virtual Machine (VM)
- Direct VM execution
- Cross-platform runtime
- Simple and readable syntax
- Automatic memory management
- Extensible architecture
- Open source
