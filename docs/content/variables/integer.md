# Integer

Integer is a data type in El that holds a round number value.

Example of Valid and Unvalid Integer Value:

| Valid | Unvalid|
| --- | --- |
| 2 | 1,9 |
| 89 | 8.9 |
| 0 | zero |
| -16 | min 16 |

## Assignment

Integer value, just can assign with integer/round number value, can't assign with another type (str, float, decimal).

Example:

```el
var int number = 10;
number = 10;
```
