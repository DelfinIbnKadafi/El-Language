# String

String is a data type in El that holds a text value. Can have value likes text, symbol, number, etc, but always legible as string/text.

String value always enclosed in quotation marks ", can't use '.

Example of Valid and Unvalid string Value:

| Valid | Unvalid|
| --- | --- |
| "Hello" | hello |
| "123456" | 123456 |
| "*&#^#^#" | zero |
| ""-16" | min 16 |

## Assignment

You can assignment string value to string variables using =:

```el
string_variables = "Text";
```

Must always enclosed in quotation marks.
