# Installation

1. Install El Virtual Machine

   Install ELVM from release section or clone repository with:
   ```
   git clone https:github.com/DelfinIbnKadafi/El-Language.git
   ```

   And then get the elvm file.

2. Compile/Run Your Code

   To run your code, use ELVM with:

   Linux:
   ```
   ./PATH_INTO_ELVM/elvm file.ell
   ```
